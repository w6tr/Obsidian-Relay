# Staging vault

This vault is a **holding area** for work done on this machine. Nothing here is final. Every note is waiting to be transferred into the main vault.

## How it works
1. New notes land in `Inbox/` — flat, no sub-folders.
2. Each note's properties say where it belongs in the main vault (`target`) and whether it's ready (`status`).
3. Weekly: notes with `status: ready` get merged into the main vault, then moved to `Transferred/`.
4. `Transferred/` is purged once a month.
