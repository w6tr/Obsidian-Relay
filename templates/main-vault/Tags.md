# Tags

The only source of valid tags in this vault. Claude may not use a tag that is not listed here; to add one, append it with a one-line meaning first.

## venture/
One per venture; must match the `venture` property slug.
- `#venture/example-venture` — the example venture

## status/
- `#status/waiting` — blocked on someone else
- `#status/next` — the next thing to do on this venture
- `#status/someday` — parked idea, not scheduled

## kind/
- `#kind/decision` — a decision was made here (also logged in [[Decisions Log]])
- `#kind/research` — findings with sources
- `#kind/meeting` — notes from a conversation
- `#kind/idea` — unvetted idea
- `#kind/log` — a dated progress entry
